# Figures

This directory contains visualizations from the Indexical Circuits experiments.

## Behavioral pilot

### Figure 1 — Register effect by truth condition

`figure1_register_effect_by_truth.png`

Shows the item-level register effect (formal agreement score minus plain agreement score) separately for false and true factual claims. Individual points represent stimulus items and horizontal markers represent condition means.

### Figure 2 — False-claim paired comparison

`figure2_false_claims_paired.png`

Shows the change in agreement score from plain to formal register for each false-claim item. Upward-sloping lines indicate increased agreement under formal register; downward-sloping lines indicate decreased agreement.
