# Results

This directory contains outputs from the Indexical Circuits experiments.

## Behavioral pilot

`pilot_behavioral_results.csv` contains the raw results from the 20-item behavioral pilot using plain and formal register conditions and counterbalanced answer-label orders.

## Figures

The behavioral pilot is summarized in two initial visualizations:

- `figures/figure1_register_effect_by_truth.png` compares register effects for false and true claims.
- `figures/figure2_false_claims_paired.png` shows the paired movement from plain to formal register for each false claim.

These visualizations are descriptive pilot outputs and should not yet be interpreted as confirmatory evidence.
