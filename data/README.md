# Validation Data

This folder contains materials used to validate the linguistic properties of the stimuli used in the Indexical Circuits project.

## Exploratory validation

The original exploratory validation materials were developed for the 20-pair pilot stimulus set.

These materials were used to assess properties including:

- formality;
- assertiveness / confidence;
- politeness;
- naturalness;
- perceived expertise / authority;
- evidential strength;
- semantic equivalence.

## Confirmatory 60-family validation

A separate confirmatory stimulus bank was subsequently developed following the exploratory behavioral pilot.

The confirmatory bank contains:

- 60 factual families;
- 240 candidate sentences;
- a 2 × 2 manipulation of truth status and linguistic register.

The four conditions are:

- True + Plain
- True + Formal
- False + Plain
- False + Formal

## Fact-verified stimulus files

Files associated with the confirmatory stimulus stage include:

- `confirmatory_candidate_bank_F001_F060_verified.csv`
- `confirmatory_candidate_bank_F001_F060_verified_audit.csv`
- `factual_verification_revision_log.csv`

The fact-verified candidate bank is the version used to generate the confirmatory human-validation materials.

## Sentence-level validation design

The 240 candidate sentences are distributed across four counterbalanced master lists and sixteen 45-item validation variants.

Each validation form contains:

- 45 sentences;
- 45 unique factual families;
- one sentence from each presented family;
- 3 blocks of 15 sentences.

Across the full 16-form design:

- all 240 candidate sentences are represented;
- every candidate sentence appears in exactly 3 validation forms;
- each form contains approximately equal numbers of the four experimental conditions.

The planned recruitment target is:

- 5 usable raters per validation form;
- 80 usable participants in total;
- 15 independent ratings per candidate sentence.

## Human rating dimensions

Sentence-level validation measures:

- formality;
- assertiveness / confidence;
- politeness;
- naturalness;
- perceived expertise / authority;
- evidential strength.

All dimensions are rated on 1–7 scales.

## Blinding

Participant-facing validation materials do not expose:

- family ID;
- truth status;
- register condition;
- experimental condition;
- factual domain;
- the study hypothesis.

## Recruitment and privacy

Live Google Form links, response-spreadsheet links, participant allocation records, and identifiable participant information are not stored in the public repository.
